# CarSales

WPF aplikace pro načítání a vyhodnocování prodejů
automobilů ze souborů XML.

## Funkcionalita
- Načítání XML souborů
- Validace vstupních dat
- Zobrazení všech prodejů
- Filtrování víkendových prodejů
- Seskupení prodejů podle modelu
- Výpočet celkových cen bez DPH a s DPH

## Použité technologie
- C# / .NET 10
- WPF
- LINQ to XML
- xUnit
